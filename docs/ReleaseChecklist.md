# 1.0 正式候选验收清单

本表只用于 `v1.0.0` 标签生成的草稿 Release。开发版 artifact 可以做回归，但不能
代替这里的最终结果；验收通过后直接发布草稿中的原文件，不重新构建。

## 1. 产物身份与自动门

- [ ] 标签、commit、`BUILD_INFO.txt` 三者一致。
- [ ] `Build and test`、`Package candidates`、Windows probe 全绿。

## 2. KDE Plasma + XCB/XWayland

记录发行版、Plasma、会话、分辨率、系统缩放、GPU 与驱动。

- [ ] AppImage 直接启动，首次提示与应用菜单入口正常。
- [ ] 透明、像素命中、置顶、焦点、任务栏、拖动和自主移动正常。
- [ ] 四向动画、待机／跑动切换、投喂和事件优先级正常。
- [ ] 气泡视觉、打字、翻页、表情、跟随和边界夹取正常。
- [ ] 设置立即生效并持久化；暂停与隐藏不持久化。
- [ ] 托盘隐藏／唤回、第二实例唤回和强杀后重启正常。
- [ ] 锁屏／解锁、睡眠／唤醒、显示关闭／恢复后不突进、不留虚影。
- [ ] Plasma Shell 重启、屏幕可用区域变化后窗口仍可见且可退出。
- [ ] 项目显示倍率 `1×`、`2×` 均实际检查。
- [ ] 连续运行至少三小时，无崩溃、卡死或持续资源增长。

## 3. Windows 11 x86-64

使用未安装 Qt、未配置开发环境的普通用户环境。记录 Windows build、系统缩放、
分辨率、GPU 与驱动。

- [ ] ZIP 解压即用，不弹控制台、不缺 DLL；未签名风险说明准确。
- [ ] 角色与气泡透明且无 DWM 矩形边框，像素命中区域正确。
- [ ] 置顶开／关、任务栏、`Alt+Tab`、启动／点击／拖动焦点正常。
- [ ] 拖动、自主移动、四向动画、投喂与事件优先级正常。
- [ ] 气泡、设置、托盘、隐藏／唤回、第二实例唤回正常。
- [ ] 隐藏期间不移动、不弹气泡；投喂或对话途中隐藏后能够正常恢复。
- [ ] 锁屏／解锁、睡眠／唤醒、显示关闭／恢复后不突进、不留虚影。
- [ ] Explorer 重启和屏幕可用区域变化后窗口仍可见且可退出。
- [ ] 100%、125%、150%、200% 系统缩放均启动并检查窗口尺寸与边界。
- [ ] 项目显示倍率 `1×`、`2×` 均实际检查。
- [ ] 连续运行至少三小时，无崩溃、卡死或持续资源增长。

## 5. 如实保留的边界

- [ ] 没有合格 GNOME 社区结果时，继续标为实验性／未验证。
- [ ] 多显示器、热插拔和混合 DPI 未实测，不写成已支持。
- [ ] niri 与原生 Wayland 不进入正式支持范围。
- [ ] README 与 Release 说明明确非官方、非商业二创、素材限制、字体 OFL、
      项目 GPL，以及 Windows 未签名风险。

## 6. 发布确认

- [ ] 所有核心失败均已关闭，不以“已知问题”放行。
- [ ] 实测环境、SHA-256、三小时结果和性能门槛已写回状态与 Release 说明。
- [ ] 若同一标签需要重跑打包工作流，确认草稿说明中的人工验收记录仍被保留；
      工作流只刷新标题和资产，不再用仓库模板覆盖已有说明。
- [ ] 草稿 Release 中的文件与验收文件逐字节一致。
- [ ] 将 `v1.0.0` 草稿转为公开 Release，不上传或替换任何新构建文件。
